## Project

**[crw-dehbi-2008-fluent-udf](https://github.com/sina-karbakhsh/crw-dehbi-2008-fluent-udf)**:
ANSYS Fluent user-defined function (C) implementing the continuous random walk
particle dispersion model of Dehbi (2008), applied to aerosol deposition in a
90° pipe bend, with a technical report, the deposition data and a statistical
test of the random-number generator.
